# Sole Trader Kit AU

Free, private, browser-only tools for Australian sole traders and freelancers:
ATO-compliant tax invoice generator (PDF), GST calculator, ABN checksum checker and
20 programmatic "invoice template by trade" landing pages.

Live: https://christransformers.github.io/soletrader-kit-au/

- Edit pages in `src/`, trades in `data/trades.json`, then `node scripts/build.js`.
- All monetisation settings: `assets/config.js` (empty = hidden).
- See **OPERATIONS.md** for how the business runs.

General information only — not tax or legal advice.
